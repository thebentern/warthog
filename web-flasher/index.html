Warthog Flasher flash from your browser

Web Serial + esptool-js. Chrome, Edge or Opera on a desktop — Safari and Firefox do not implement Web Serial.

This browser does not support Web Serial. Use Chrome, Edge or Opera on macOS, Windows or Linux.

1 · Firmware

Load a .factory.bin you built yourself — .pio/build/warthog-<env>/firmware.factory.bin. Written to 0x0, same as a release asset.

2 · Put the board in download mode

The HaLow add-on drives USB-OTG, so the board cannot be reset into the bootloader over the wire. Do it by hand:

  1. Hold BOOT
  2. Tap RESET
  3. Release BOOT

It then enumerates as an Espressif ROM device (303a:0009) and stays there until flashed or reset. If it is already running warthog you can also send AT+DLMODE over the console.

Mesh data plane (mesh build only)

      
      
      
Applies immediately and persists; the node re-peers within ~2 s.
      Keyed is not a security feature and cannot reach OpenMANET. It encrypts
      frames with a constant compiled into every warthog, so anyone holding the
      firmware holds the key, and a peer without that exact constant — which is
      every non-warthog node — cannot decrypt anything. Peering is unauthenticated
      either way. Real per-link keys need SAE/AMPE, which is not implemented.
